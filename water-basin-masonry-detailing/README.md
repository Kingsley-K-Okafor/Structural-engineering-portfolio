# Water Basin / Masonry Detailing (US)

### 🔍 Project Summary
Detailing of masonry and reinforced concrete components for a water basin structure, focusing on clarity and coordination.

### 🛠️ Key Responsibilities

- Coordinated openings and embedded elements with architectural layouts  
- Maintained consistent notation across drawing sets  

### 📈 Engineering Value

- Reduced coordination conflicts between disciplines  
- Ensured accurate interpretation of design intent  

### 🧠 Skills Demonstrated
- CMU and reinforced concrete detailing  
- Structural coordination  
- Technical documentation  
- Construction detailing
